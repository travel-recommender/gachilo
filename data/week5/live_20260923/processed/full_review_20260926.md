# 전체 150곳 주소·영업시간 검토 (2026-09-26)

- 장소 ID·OSM 참조·좌표·분류·150개 선택을 유지했습니다.
- 공식 사이트, 시설 운영사, 시청·관광기관에서 확인한 사실만 변경했습니다. 유료 Google API 호출은 없습니다.
- 실패한 페이지 조회와 미확인 항목도 전 장소에 기록했습니다. 전체 검토가 전체 검증 완료를 뜻하지 않습니다.
- 검증 날짜는 해당 필드의 확인 날짜입니다. 장소 전체의 운영 보증이 아닙니다.
- 설명형 영업시간은 자동 일정 생성 전에 정규화해야 합니다. 휴관·예약·공휴일 예외를 함께 적용해야 합니다.
- recommendation_blockers는 검토용 표시입니다. 추천 코드에서 자동 제외하도록 연결한 것은 아닙니다.
- place_review_queue.md에 전체 장소별 값·출처·남은 확인사항이 있습니다.

## 다시 적용

기존 수집 → 카페 지점 교체 → 2026-09-24 보완을 반영한 동일 150곳 데이터에 다음 검토 기록을 적용합니다. 스크립트는 전 장소 ID와 OSM 지점이 일치할 때만 실행되며 재실행해도 중복 기록하지 않습니다. 주소·시간의 변경 전 값은 검토 기록의 previous_values에 보존됩니다.

```sh
python3 scripts/apply_place_review.py INPUT_JSON data/week5/live_20260923/processed/official_enrichment_20260926.json OUTPUT_JSON
```

입력 파일과 출력 파일을 구분하여 결과를 먼저 검토하세요. 이 명령은 장소 JSON만 갱신하며 보고서·manifest는 재생성하지 않습니다. 초기 수집 스크립트를 재실행하면 검토 보완이 사라질 수 있으므로 기록 파일을 유지해야 합니다.
