# 시연용 최종 장소 목록 (2026-10-30)

최종 CSV 150곳 + 기존 추가 55곳 + 카페·식당·간식·관광 보완 20곳 = **225개 검색 목록**이다.
새 20곳의 공식 정보·지도 후보/OSRM 11곳 대조와 보관/역/휴식 보조자료 5건은 [10/30 수집 기록](../collections/osaka_traveler_expansion_20261030/README.md)에 있다. 새 20곳은 자동 일정 검증 전이며 보조자료 5건은 화면 미연동이다.
기존 150곳 ID를 유지하며, 추가 수집표의 기존 장소 보완 3건은 자동 덮어쓰지 않고 update_proposals로 보존한다.

- 서비스 기본값은 `data/runtime_catalog.json`이다. Python API와 Node의 단일/세 후보 계산이 같은 225곳과 날짜 규칙을 읽는다.
- 팀원 실행 방법: [최종 데이터 테스트 안내](../../docs/final_catalog_team_setup.md). 기존처럼 `backend`에서 `python3 server.py`, `web`에서 `npm run dev`로 실행한다.
- API: `http://localhost:8000/api/places?limit=150&offset=0`. 다음 페이지는 `next_offset`을 사용하며 화면은 모든 페이지를 읽는다.
- `REAL_CATALOG_PATH`·`REAL_PROFILES_PATH`를 함께 지정하면 다른 검증본을 시험할 수 있다. 오래된 개인 설정이 있으면 둘 다 해제한다.
- 기존 DB·방·입력·결과는 지우지 않는다. 저장 후보는 입력 재제출 후 새 revision으로 계산해야 새 데이터가 반영된다.

## 확인 상태

검색 목록 전체가 일정 배치 확정 데이터라는 뜻은 아니다. 원본 CSV의 9개 제외 기록은 이유와 함께 표시하고 새 선택을 막는다. 나머지 장소는 희망 목록에 선택할 수 있지만 날짜·운영 조건 검증에서 배치되지 않을 수 있다.
추가 55곳은 별도 `branch_verification_20261026.json`으로 검토했다. **51곳은 2026-10-26~2026-11-30 날짜별 시연 일정에 사용할 수 있고, 4곳은 자동 배치 보류**다. 검색 목록에는 모두 남긴다. 원본 CSV·수집표·기존 보완 제안은 바꾸지 않는다.

- 일정 보류: girls mignon 신사이바시, petit mignon 다이마루 신사이바시(공식 사이트 점검으로 최신 영업·입장·가격 확인 부족), 와나카 센니치마에·도톤보리(공식 최신 메뉴 가격 부족).
- 좌표는 공식 점포 지도 또는 공식 주소와 대조한 지도/건물 기준점이다. 실측 출입구·실내 경로가 아니다. girls mignon 좌표는 미확정 null을 유지한다.
- 체류시간·짐 점수는 **시연 추정**으로 구분한다. 쇼핑30분, 백화점180분, 식당90분은 기존 사용자 범위 상한을 사용하며 포장·간식20분은 추가 시연 기준이다. 대기열은 포함하지 않는다.
- 같은 건물의 입점 매장끼리 이동은 각5분으로 추정하고 내부 보행 거리는 합계에서 제외한다. 그랜드프런트 북관/남관, 다이마루 본관/남관은 서로 다른 건물이다. 건물과 입점 매장을 둘 다 선택하면 체류시간을 각각 합산한다.
- 쇼핑 구매액은 미산정이며 무료라는 뜻이 아니다. 음식점은 지점별 메뉴/수량/세금 조건을 보존한다. 후쿠타로 우메다는 공식 평균예산2,500엔을 사용하며 **메뉴 확정가가 아닌 추정**임을 화면과 후보 설명에 표시한다.
- 551 다카시마야점은 포장 방문으로 점심·저녁 끼니를 대체하지 않는다. 후쿠타로 우메다는15~17시 휴식 구간을 비운다. 최종입장/주문 마감 및 체류 종료 시각을 검사한다.
- 닌텐도 오사카의 주말·공휴일 입장 확인, 닌텐도/포켓몬 오사카11월17일 휴업 및18일 이후 추첨·정리권 확인, 551 본점11월10/17일·난바워크11월18일 휴무, 다이소 신사이바시 공휴일 미확인 등은 날짜별로 차단한다. 확정되지 않은 입장권을 확보했다고 가정하지 않는다.
- 51곳이 어느 날짜에나 모두 배치된다는 뜻은 아니다. 날짜·예산·선택·걷기·활동시간 한도에 따라 최종 일정이 달라진다. 방문일 범위를 벗어나면 다시 검토해야 한다.

원본의 체험·오락 / 복합문화 표시 분류를 유지한다. 미확인 비용을 무료로 표기하지 않는다.
기존 일정 규칙과 시간·요금·지점 정보가 달라진 9개 장소는 오래된 날짜 규칙을 무효화했다. 새 규칙을 검증하기 전까지 자동 배치하지 않는다. 최신 CSV의 모든 확인 메모와 기존 일정 차단 조건을 함께 보존한다.

## 재생성

`python3 scripts/build_expanded_catalog.py` (저장소의 `reviewed_places_20261014.csv` 사용; 원본과 같은 SHA-256)

CSV를 읽기만 하며 원본은 수정하지 않는다. 입력 파일 이름과 SHA-256은 catalog의 input_provenance에 기록한다. 수집표는 data/collections/osaka_branches_20261019/branches.json을 사용하며 검증 overlay의 collection SHA와 모든 ID가 일치해야 한다. 검토 근거 URL, 확인일, 좌표 종류, 남은 항목은 overlay에서 확인할 수 있다.

검증: `python3 scripts/test_expanded_catalog.py`, `python3 scripts/test_final_catalog.py`, `node --test scripts/test_verified_branches.mjs`, `NODE_BINARY=/path/to/node python3 scripts/test_final_catalog_flow.py`. 신규51곳 각각의 실제 세 전략 계산, 보류4곳 차단, 날짜 예외·휴식·포장·건물 이동, 225곳 페이지 로딩 및 방장 확정·전원 동일 결과·DB 재조회를 확인한다. Node24이상 필요.

과거 감사용 `loadInputs()`는 150곳 정본을 유지한다. 서비스의 `loadRuntimeInputs()`만 최종 목록을 읽는다. 기존 보고서 정본은 이 변경에 포함하지 않는다.

`legacy_catalog_validation_20261026.json`은 현재 엔진의 역사 데이터 재현 비교용이며, 과거 보고서·원본을 덮어쓰지 않는다.
