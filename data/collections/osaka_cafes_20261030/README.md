### 최초 검사

- 기존 수집기 스키마 검증 통과.

- 8개 ID 중복 없음, 두 번째 적용 시 추가 0곳.

- 기존 55곳 수집표·날짜 프로필·실행 중인 테스트본은 변경하지 않음.
