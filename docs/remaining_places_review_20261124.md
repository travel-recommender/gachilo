# 잔여 장소 검토 — 2026-11-24

이 기록은 전체 잔여 장소의 검증 완료를 뜻하지 않는다. 기존 실험 스냅샷을 변경하지 않으며 새 후보의 적용 기간은 2026-11-24~30이다. 실시간 영업·티켓 잔여 수량은 보장하지 않는다.

- **블루보틀 우메다 차야마치 카페**: [공식 지점 안내](https://store.bluebottlecoffee.jp/pages/umeda-chayamachi)의 주소 및 08:00~21:00과 [타베로그 2026-06 방문 후기](https://tabelog.com/osaka/A2701/A270101/27123735/dtlrvwlst/B530108959/)의 라테 737엔을 대조했다. 가격은 현재 확정가가 아닌 1인 음료 예산 참고치다. 실내 카페 휴식이며 식사 대체가 아니다. 실제 가격·임시휴무는 재확인이 필요하다.
- **오사카 나카노시마 미술관**: [공식 전시 안내](https://nakka-art.jp/exhibition-post/daiei-ten2026/)의 4층 ‘대영박물관 일본미술 컬렉션’ 전시를 기준으로 10:00~17:00 및 최종입장 16:30, 일반 성인 당일권 2,300엔을 사용한다. 11월 24일 대체휴관과 30일 월요일 휴관을 각각 반영했다. 금요일 연장시간은 편의상 사용하지 않는다. 학생할인, 다른 전시, 매진 및 임시휴관은 별도로 확인해야 한다.
- **유니버셜 스튜디오 재팬**: [공식 일정](https://www.usj.co.jp/web/ja/jp/park-guide/schedule/park-hour2)으로 11월 25일 09:00~21:00, 26일 08:30~21:30을 확인했다. [여행사 11월 달력](https://jp.trip.com/blog/usj-golden-week/)과 [11월 3일 가격 확인 기사](https://kansai-tabijitaku.com/usj-christmas/)는 성인 1일 입장권 9,400엔으로 표기한다. 공식 판매 페이지는 직접 열리지 않았고, 다른 보도에는 8,600엔이라는 상충 금액도 있어 9,400엔을 **방문일의 확정가가 아닌 예산 참고치**로 사용한다. 구매 전 공식 판매처의 실제 가격·잔여분을 확인해야 한다. 실제 체류시간과 줄, 유료 익스프레스 패스·식사·일부 구역 정리권은 별도다.

유니버셜은 이전에 공식 확인한 11/17~19의 9,900엔과 해당 날짜별 시간을 보존한다. 기존 확인 기간과 새 기간 사이인 11/20~24는 확인이 부족하므로 자동 일정에서 계속 차단한다.

- **가이유칸**: 11/25 10:30~20:00·최종입장 19:00, 성인 2,800엔은 [방문 가이드](https://jptripcard.com/osaka/kaiyukan/)와 [일본 일정 자료](https://asobimiru.com/kaiyukan/)가 일치하지만 공식 동적 달력을 직접 읽지 못해 참고값으로만 사용한다. [공식 FAQ](https://www.kaiyukan.com/info/faq/)에 따르면 사전 예약 없이도 당일 시간 지정 티켓을 구매할 수 있지만 원하는 시간의 잔여가 없거나 대기할 수 있다. 최종 일정 시간은 직접 티켓과 맞춰야 한다. 11/25 외 날짜는 이 검토만으로 승인하지 않는다. 공식 지도에 연결된 기존 시설 좌표는 입구 현장 실측이 아니고 120분 체류는 일정 추정이다.
- **칼디 난바 CITY점**: [공식 지점](https://map.kaldi.co.jp/kaldi/detailMap?account=kaldi&adr=27&bid=567&pgret=2)은 본관 1층·11:00~21:00으로 안내하며, [지도 목록](https://www.mapion.co.jp/phonebook/M02014/27128/22733043053/)의 주소·전화도 일치한다. 지도 지점 좌표를 참고하되 실제 매장 입구·층간 이동은 실측하지 않았다. 30분 체류·짐 점수는 계획 추정이며, 쇼핑 구매비는 개인차로 미산정한다. 11/25 제한 프로필을 사용하고 시설·매장 임시휴업을 별도 확인한다.

- **칼디 덴노지 MIO점과 루쿠아 이레점**: [MIO 공식 안내](https://www.tennoji-mio.co.jp/shop/detail/186)는 플라자관 지하 1층 09:00~21:00, [루쿠아 이레 공식 지점 안내](https://map.kaldi.co.jp/kaldi/detailMap?accmd=0&account=kaldi&arg=&bid=375)는 2층 10:30~20:30이다. 각 [MIO 지도](https://mapfan.com/spots/S5W34%2C6661%2CMGPJP0), [루쿠아 이레 지도](https://mapfan.com/spots/S5W34%2C6661%2C4WAXP0)의 서로 다른 좌표를 사용했다. 11/25만 계획에 사용하며 매장·시설 임시휴업, 실제 출입구와 쇼핑 구매비는 별도로 확인한다.
- **스타벅스 에비스바시·난바 난카이도리점**: [에비스바시 공식 지점](https://store.starbucks.co.jp/detail-2005/)은 08:00~22:30이나 [상점가 안내](https://ebisubashisuji.or.jp/shops/tsutaya_ebisubashi/)는 22:00까지여서 더 짧은 시간을 사용했다. [난카이도리 공식 지점](https://store.starbucks.co.jp/detail-4555/)은 07:00~22:30이다. 이 지점은 가격 B, 에비스바시는 A가 적용된다. 두 곳 모두 **460엔은 실제 지점 확정가가 아니라** [입지 A의 2026년 10월 커피 가격 보도](https://www.foodrink.co.jp/sp/detail.php?blog_id=4&entry_id=17482)에 기초한 1잔 예산 추정치다. 난카이도리 B 가격은 직접 확인하지 못했다. 불규칙 휴업을 확인하고 11/25에만 사용한다. 휴식 40분은 계획값이며 식사나 짐 보관 보장이 아니다.
- **소라니와 온천**: [운영사 발표](https://www.kyodo.co.jp/pr/2026-11-13_4049108/)의 11:00~23:00, 최종입장 22:00과 부정기 휴관을 확인했다. [평일 정상 요금 안내](https://www.club-off.com/dxfukuri/apps/top/AASC22411.cfm?AREA=0&LNO=1&PNO=2&RECID=29487&TNO=1&action=AASC22411003&sub_action=)의 상한 2,640엔에 입탕세 150엔을 더한 2,790엔은 **예산 추정**이며 11/25 확정 요금이 아니다. [동일 건물 2층 시설](https://locationsdb.com/ja/brands/gashapon-department-store)의 위치를 건물 기준점으로 썼고 실제 입구는 확인하지 않았다. 옥상 정원이 있어 전체를 실내로 처리하지 않는다. 이용 제한·문신 관련 규정, 임시 휴관 및 티켓 잔여는 방문 전 직접 확인한다.
- **오에이피 항구**: [운항사 2026년 안내](https://suijo-bus.osaka/pdf/Aqualiner.pdf)는 해당 항구가 운휴 중이라고 명시한다. 영구 폐쇄로 단정하지 않으며 재개 확인 전 일정에는 넣지 않는다.
- **파르페 드 메릴리**: [현재 바바초 지점의 공식 안내](https://parfait-de-merrily.owst.jp/)와 [타베로그](https://tabelog.com/osaka/A2701/A270104/27148141/)를 대조해 종전 시간 표기를 월~목·토·일 09:00~18:30, 금요일 09:00~20:00으로 고쳤다. [이전 남선바 지점은 이전](https://tabelog.com/osaka/A2701/A270201/27132337/)한 곳이다. 비정기 휴무와 실제 가격은 아직 확인이 필요해 일정 투입은 보류한다.

좌표는 지도·건물 기준점으로 실제 입구 실측은 아니다. 날짜별 적격성과 A·B·C 후보 배치는 유료 외부 호출 없는 모의 확인으로 검사한다.
