# 11월 23일 실험 피드백 적용

사용자 요청으로 P3 추천 카드를 모든 참가자에게 켜고, P4 꼭 가기를 선택 사항으로 바꾼다. 5곳은 권장 수이며 0곳·1~4곳·6곳 이상도 저장·진행할 수 있다. P3의 6곳 이상 담기와 목록 30곳 한도는 유지한다. P4는 모인 실제 카탈로그 장소 수까지 선택할 수 있다. 추천에서 담은 장소가 꼭 가기로 자동 지정되지는 않는다.

P3 추천은 함께 담긴 기록을 우선하고, 자료가 적으면 같은 지역·카테고리에서 여행 기간에 방문 가능한 곳으로 채우는 서버 추천이다. 솜솜AI가 고른 장소라고 표시하지 않는다. P7/P8의 AI 빈자리 채우기는 별도 기능이며 원래 일정이 충분하거나 검증을 통과하지 못하면 AI 추가 장소가 없을 수 있다. 규칙으로 채운 곳을 AI 추천으로 바꾸지 않는다.

P4에서 장소를 펼칠 때 Google Places 사진 하나를 조회한다. 등록된 지점과 Google 장소 ID가 수동 연결되었거나, 공식 이름이 같고 좌표 150m 이내에 유일하게 일치할 때만 표시한다. 사진·출처·사진 참조는 DB나 카탈로그에 저장하지 않는다. Google Maps와 촬영자 출처를 표시한다. 사진이 없거나 실패하면 지도에서 사진 보기 링크를 제공하며 꼭 가기·제외 조작은 계속 가능하다. 카드가 접혀 있을 때는 호출하지 않고 자동 재시도도 하지 않는다. API 키는 서버 환경변수에서만 사용한다. 요청당 최대 검색·상세·사진 3회가 발생할 수 있으므로 Google 사용량 확인이 필요하다.

걸음 수 표시는 `장소 간 도보 · 하루 평균`으로 구체화한다. 실제 계산은 모든 여행 날짜의 장소 간 도보 걸음 수 합을 여행 일수로 나눈 값이다. 하루 상한은 구성원 최솟값(예: 20,000·20,000·16,500 → 16,500)이며 목표 걸음 수가 아니다. 숙소 왕복·관광지 안에서의 걷기는 현재 계산에 포함되지 않는다. 700걸음대라는 특정 참가 결과의 정확성은 결과 기록을 별도로 확인해야 한다. 값을 임의로 입력 평균에 맞추지 않는다.

## 배포·분석 구분

현재 운영 세션 `team-20261116-v1`은 기존 코드·자료·추천 비활성 정책으로 동결됐다. 새 코드로 시작하려면 새 `EXPERIMENT_SESSION`을 사용한다. 기존 세션과 DB·링크·PIN을 덮어쓰거나 초기화하지 않는다. 새 그룹 링크·PIN을 다시 배포하고, 이전 세션 결과와 새 정책 결과를 구분해서 분석한다.

새 묶음은 `inputPolicy=optional-must-v1`, `recommendationCards=enabled_all_participants_v1`, `placePhotos=on-demand-google-v1`을 기록한다. P7/P8의 참가자별 설명 조건(`participant-fixed-v2`)은 유지하지만 P3 추천 근거·사진 노출이 추가되므로, 기존 실험과 동일 조건으로 합치지 않는다.
