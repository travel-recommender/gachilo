## 서버에서 확인한 근거

Railway의 현재 배포 및 관리자 상태와 2026-11-25 11:17:41~11:26:27 KST의 제한된 HTTP 로그 표본을 대조했다.

- 후보 계산 POST 1건이 HTTP 200으로 완료됐다(11:21:09 KST).
- 결과 조회 GET이 HTTP 200으로 응답했고 결과·상세 일정 화면 경로가 로드됐다.
- 장소 추천 API와 장소 사진 API의 정상 응답을 확인했다. 사진 API의 HTTP 429 응답 1건도 표본에 있어 사진 요청 제한 동작은 별도 개선 검토 대상이다.
- 결과 생성 이후 입력 수정 요청은 HTTP 409로 거절됐다. 원래 실험의 결과 이후 입력 잠금 정책과 일치한다.
- 조은·혜인·윤진 친구 방은 각각 제출 0건이다. 완료로 기록하지 않는다.

관리자 상태의 `results=0`은 구형 단일 결과 테이블만 세는 수치다. A/B/C는 `candidate_results`에 따로 저장하므로 이 수치만으로 후보 미저장을 판단하면 안 된다. 이번 확인은 성공한 계산·조회 응답까지이며, 원본 DB의 후보 행수·해시와 내보낸 근거 파일을 직접 검증한 것은 아니다.
