## 카테고리 분류 기준 — 2026-10-12

주요 방문 목적을 기준으로 한 장소에 한 분류를 부여한다. `체험·오락`은 직접 참여하거나 놀이·오락 시설을 이용하는 방문을 뜻한다. 게임센터·아케이드, 테마파크·놀이기구, 공방 체험 등이 해당한다. 게임을 판매하는 상점은 쇼핑, 게임의 역사·작품을 주로 전시하는 박물관은 문화로 구분한다. 전시와 체험이 함께 있으면 선택한 방문 프로그램의 주목적과 근거를 메모한다.

실제 수집 데이터/API에는 `체험·오락`, 기존 화면·엔진에는 `activity`를 사용한다. 기존 `activity`의 표시명 `체험`을 확장한 것으로 새 엔진 ID를 만들지 않는다. 이번 적용 대상은 레트로 게임 이용 장소인 **엘레메카 연구소**(`osaka_draft_2e4698946819`)다. 장소 ID와 원본 OSM 태그는 유지하고 분류 근거를 `field_sources.category`에 `team_category_rule`로 기록한다.

분류 변경만으로 영업시간·비용·실내 여부를 검증한 것으로 처리하지 않는다. 체험·오락 공통 체류시간은 아직 합의되지 않았다. 엘레메카의 기존 120분은 종전 명소 규칙의 추정값으로 남기고, API `planning.stay_range`의 유형은 `미합의(체험·오락)`, min/max/representative는 null로 표시한다. `stay_basis`에도 이전 추정값임을 적고 `stay_policy_unconfirmed` 보류 사유를 유지한다. 일정 승격 전에 장소별 소요시간 또는 팀 규칙을 확인한다. 이미 합의된 테마파크 360~480분 하위 유형은 유지한다. 데모의 `activity` 기본 비용·시간·covered를 실제 수집 장소에 복사하지 않는다.

## 검토 정보

16개 장소 필드 외에 JSON의 review에 원본 파일·행 번호·누락 항목·검토 상태를 둔다. 신규 장소의 상태는 needs_verification, 기존 장소는 existing_not_reverified다. 원본 SHA-256을 상단에 저장해 선별에 사용한 입력을 추적한다.

빈칸은 JSON에서 null이다. null을 0·false·24시간 영업으로 대체하지 않는다. 향후 추천 기능은 영업시간이 미확인인 장소를 별도로 표시하고, 가격이 없는 장소를 무료라고 계산하지 않아야 한다.

OSM 재수집 시 객체 종류(node/way/relation), ID, 원본 태그, 수집일, 좌표 산정 방식과 출처를 함께 저장한다. 기존 CSV에서 사라진 이 정보는 임의로 복원하지 않는다.


## 2026-09-28 공식 출처 보완 규칙

- 현재 150개 데이터의 `area`는 공식 주소에서 확인되는 오사카시 행정구입니다. 관광 권역은 별도 설계 대상입니다.
- `cost`는 일반 입장권 또는 특정 메뉴·코스·이용권의 1인 JPY입니다. `field_sources.cost.note`의 적용 범위를 확인해야 합니다.
