# 장소 데이터 작성 기준 초안

기존 16개 필드와 ID를 유지한다. 이 문서는 5주차 팀 검토용이며 미확인 값을 채우는 근거로 사용하지 않는다.

| 필드 | 형식 | 작성 기준 |
| --- | --- | --- |
| place_id | 문자열 | 기존 ID 보존. 신규 초안은 이름·좌표 해시 기반 osaka_draft_ 접두사. 좌표 수정 시에도 발급된 ID는 유지하는 저장 구조로 전환 필요 |
| name | 문자열 | 원본 장소명과 지점명 유지 |
| name_ko | 문자열 또는 null | 확인된 한국어명. 번역값은 별도 출처 메모 후 입력 |
| category | 문자열 | 명소·문화·자연·쇼핑·카페·식사 중 하나 |
| area | 문자열 또는 null | 팀에서 정한 지역명. 좌표만으로 행정구역을 추정하지 않음 |
| address | 문자열 또는 null | 공식 지점 페이지 또는 OSM 주소 태그 확인 |
| latitude / longitude | 숫자 | WGS84 위도·경도. 출입구 좌표인지 도형 대표점인지 출처에 기록 |
| opening_hours | 문자열 또는 null | 원문 유지. 자유 서술을 자동으로 영업 중으로 해석하지 않음 |
| cost | 0 이상 숫자 또는 null | 제안: 1인당 필수 방문 비용, JPY. 식사는 기준 메뉴 비용. 쇼핑 구매액은 별도 예산으로 처리. 기존 0은 무료 입장일 수 있으며 총 지출 0을 뜻하지 않음 |
| stay_min | 양수 숫자 또는 null | 제안: 장소 체류 분, 이동·대기 시간 제외. 예상값은 사실값과 구분해 근거 기록 |
| bag_load | 숫자 또는 null | 제안: 0~3 상대 지표, kg 아님. 0 증가 없음·1 소형·2 보통·3 큼. 구매 여부에 따라 달라지므로 팀 확정 전 자동 채움 금지 |
| covered | true / false / null | 제안: 주요 체험 구역이 실내/지붕으로 보호되는지. 혼합 시설은 null과 메모 사용. 비가 와도 전체 방문이 안전하다는 뜻은 아님 |
| website | 문자열 또는 null | 실제 지점의 공식 링크인지 확인. URL이 있다는 것만으로 검증 처리하지 않음 |
| opening_hours_source | 문자열 또는 null | 영업시간 근거 페이지. 확인하지 않은 URL은 근거로 새로 기입하지 않음 |
| verified_at | YYYY-MM-DD 또는 null | 실제 출처 확인일. 데이터 가공일을 넣지 않음. 기존 날짜도 이번 재검증을 의미하지 않음 |

## 검토 정보

16개 장소 필드 외에 JSON의 review에 원본 파일·행 번호·누락 항목·검토 상태를 둔다. 신규 장소의 상태는 needs_verification, 기존 장소는 existing_not_reverified다. 원본 SHA-256을 상단에 저장해 선별에 사용한 입력을 추적한다.

빈칸은 JSON에서 null이다. null을 0·false·24시간 영업으로 대체하지 않는다. 향후 추천 기능은 영업시간이 미확인인 장소를 별도로 표시하고, 가격이 없는 장소를 무료라고 계산하지 않아야 한다.

OSM 재수집 시 객체 종류(node/way/relation), ID, 원본 태그, 수집일, 좌표 산정 방식과 출처를 함께 저장한다. 기존 CSV에서 사라진 이 정보는 임의로 복원하지 않는다.
